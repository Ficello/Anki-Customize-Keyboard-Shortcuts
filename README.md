# Customize Keyboard Shortcuts (Enhanced Edition)

An advanced keyboard shortcuts manager and interactive visualizer for Anki. Inspired by Adobe After Effects and professional creative suites, this add-on provides an interactive virtual keyboard, native layout detection, bi-directional binding, and advanced detection of third-party add-on shortcuts.

---

## Key Features

1. **Interactive Virtual Keyboard**
   - Full visual layout rendering in real-time.
   - Live modifier key detection (`Ctrl`, `Alt`, `Shift`).
   - Dynamic key binding display directly on each keycap.

2. **Native Keyboard Layout Support**
   - Automatic Windows layout detection.
   - Built-in support for **AZERTY (FR)**, **QWERTY (US)**, **QWERTZ (DE/CH)**, **Dvorak**, and **Colemak**.

3. **Third-Party Add-on Scanner**
   - Discovers and displays shortcuts registered by other add-ons (e.g., Anki EDN ecosystem, Diff viewers, Card Managers).
   - Resolves human-readable add-on names and scope (Main window, Editor, Reviewer, Browser).

4. **Multi-Language Support (i18n)**
   - Fully localized in **French (`fr_FR`)**, **English (`en_US`)**, and **Chinese (`zh_CN`)** with automatic detection.

5. **Safe & Non-Destructive**
   - Instant search and category filtering.
   - Reset to defaults at any time.
   - In-app key sequence recorder.

---

## Installation & Usage

1. Restart Anki after installation.
2. Open **Tools** > **Customize Keyboard Shortcuts** (or press your configured shortcut).
3. Click on any key on the visual keyboard or browse the command table to edit shortcut assignments.
4. Click **Apply** or **OK** to save changes.

---

- PyQt6 & Qt5 compatible
