# Anki 快捷键设置插件

此插件允许您自定义 Anki 中的各种快捷键，使您可以更高效地使用 Anki。

## 功能

1. 通过图形界面自定义所有 Anki 快捷键
2. 一键禁用所有快捷键
3. 一键恢复默认快捷键设置
4. 按功能分类管理快捷键，易于查找
5. 搜索功能，快速定位想要修改的快捷键

## 使用方法

1. 安装插件后，在 Anki 主界面的"工具"菜单中会出现一个新的"快捷键设置"选项。
2. 点击此选项，打开快捷键管理器对话框。
3. 在对话框中，快捷键按照功能区域分类为不同的标签页：
   - 主界面
   - 编辑器
   - 复习界面
   - 浏览器
   - 工具栏
4. 要修改快捷键，只需在对应的输入框中输入新的快捷键。
5. 要禁用快捷键，请在输入框中输入`<nop>`。
6. 点击"禁用所有快捷键"按钮可以将所有快捷键设置为`<nop>`。
7. 点击"恢复默认设置"按钮可以恢复所有快捷键的原始设置。
8. 完成修改后，点击"应用"或"确定"按钮保存更改。

## 快捷键格式

快捷键可以使用以下格式：

- 单个按键：`A`、`B`、`1`、`2`、`Space`等
- 组合键：`Ctrl+C`、`Shift+D`、`Alt+F4`等
- 特殊键：`F1`、`Home`、`End`等
- Qt 特殊键：`Qt.Key_Return`、`Qt.Key_Enter`等
- 禁用快捷键：`<nop>`

## 注意事项

1. 修改快捷键后，需要重启 Anki 才能生效。
2. 请避免设置与系统或其他 Anki 功能冲突的快捷键。
3. 如果您忘记了原始设置或配置出现问题，可以随时使用"恢复默认设置"功能。
4. 搜索框可帮助您快速找到想要修改的快捷键。

## 常见问题

**Q: 我的快捷键设置没有生效？**  
A: 请确保在修改后重启了 Anki。某些快捷键可能与系统或其他程序冲突，请尝试使用不同的组合。

**Q: 如何查找特定的快捷键？**  
A: 使用对话框顶部的搜索框，输入功能名称或快捷键，系统会自动过滤出匹配的项目。

**Q: 我可以设置多个按键序列作为快捷键吗？**  
A: 是的，可以使用逗号分隔多个按键序列，如`Ctrl+K, Ctrl+C`表示先按`Ctrl+K`再按`Ctrl+C`。

**Q: 如何完全禁用某个快捷键？**  
A: 将其设置为`<nop>`即可禁用该快捷键。
